
`npm install` för att installera allt

`npm run dev` för att starta programmet

alternativ
```
npm run build
npm run start
```
för att starta

`npm run lint` kollar fel i koden

`npm run test` och `npm run test:watch` kör alla jest-tester till projektet





.env-fil
```
PORT=3000
NODE_ENV=development
```
